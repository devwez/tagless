# snake

a boring snake game in one html file for tagless.

## how it works

a requestanimationframe loop on a grid where the snake can move on. eat apples and get skins.

## features

- menu
- skins
- swipe / wasd / arrows to move
- high score

## run it

```powershell
npx http-server . -p 8080
```

then `http://127.0.0.1:8080`. live demo: https://tagless-zeta.vercel.app
